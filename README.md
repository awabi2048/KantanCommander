# KantanCommander

## 起動トリガー詳細設定の画面仕様

## 参照画面と維持する部分

- 起動方法（レッドストーン入力／タイマー／トリガー）の選択画面は、従来の子画面の配置・背景・素材・操作を維持します。
- イベント種別の選択画面も従来の2列カード、1ページ6件、ページャ、戻る位置を維持します。種別の統合により表示件数だけ7件（6件＋1件）になります。
- イベントを1回クリックすると候補を選択し、同じ候補の再クリックで「詳細設定」へ進みます。選択中は白の縁、保存済みは水色の縁で示します。

## 詳細設定

- 詳細子画面だけ、一般コマンド設定と同じタブ列描画を使用します。左に「誰が」「対象」、操作条件のあるイベントには「どう操作したか」を加えます。タブの配置・寸法・文字サイズ・選択中の幅の伸び方とシアンの背景は共通です。
- 詳細子画面の固定操作は「戻る」と「確定」です。一般コマンド設定の「複製」「削除」は表示しません。タブのクリックIDは詳細画面専用とし、仮設定の切替へ接続します。
- 右側の値行は設定画面の共通部品を使用します。詳細画面では選択中タブに白の縁、未選択で設定済みのタブに水色の縁も加え、操作上の選択と保存状態を混同しません。
- 右側に固定のイベント名と選択中タブの現在値を表示します。設定値をボタン名へ混ぜません。
- 「誰が」は発生したプレイヤーを対象とする条件です。汎用の対象指定と共通の `TargetSpec` で名前・タグ・ゲームモードを指定でき、個体IDでも絞り込めます。操作者不明の信号変化には一致しません。
- 「対象」はブロックなら素材とワールド・整数座標、エンティティなら汎用 `TargetSpec` の種類・名前・タグおよび個体IDで絞り込めます。視線先の個体を取得する操作もあります。未指定は対象を絞り込みません。
- 操作条件は、レバーでは「指定しない／オンにした／オフにした」、ブロックとエンティティでは「指定しない／左クリックした／右クリックした」から選びます。
- 各入力は確定までは画面内の仮設定だけを更新します。「確定」で一括保存し、「戻る」では仮設定を捨ててイベント選択へ戻ります。

## 発火時の意味

- ブロック破壊・設置は別種別のままです。ボタンと感圧板は作動した時だけ起動します。レバーは変化後のオン／オフ、クリックは左右を詳細条件として照合します。
- ブロック右クリックにはAIRへの操作も含めます。このとき `event_block=AIR` です。`event_position` は視点からブロックの `interaction_range` の先端まで進んだ座標です。実際にクリックされたブロックはないため、個別ブロック座標の条件には一致しません。
- AIRの操作イベントはPaper側が初めからキャンセル状態で渡す場合があるため、AIRだけはその予測キャンセルを理由に除外しません。両手の二重発火は主手だけを採用して防ぎます。
